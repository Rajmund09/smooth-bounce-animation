# 🎯 Smooth Bounce Animation

A clean and modern **CSS-only animation** featuring a smooth horizontally moving ball with a vertical bounce effect. Built using pure HTML & CSS—no JavaScript required.

---

## ✨ Features

- 🎨 Gradient background & ball
- 🔁 Infinite smooth animation
- 🧠 Uses cubic-bezier easing for realistic motion
- ⚡ Lightweight & fast (pure CSS)
- 📱 Fully responsive container

---

## 🛠 Tech Stack

- HTML5  
- CSS3 (Keyframes, Gradients, Transforms)
